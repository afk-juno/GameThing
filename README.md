# PHALANX C-RAM — Missile Defense

A simple Space Invaders–style shooter where you operate a **Centurion C-RAM / LPWS** (land Phalanx) and stop incoming anti-ship missiles with a dense 20mm tracer stream before they hit the ship.

## Play locally

1. Open `index.html` in a browser (Chrome, Edge, or Firefox).
2. Click **ENGAGE** (or press Space).
3. Move the mouse / finger to aim. Hold click / touch to fire.

## Controls

| Input | Action |
|--------|--------|
| Mouse / touch | Aim turret |
| Hold click / touch | Fire continuous tracer stream |
| Space | Start / restart |

## Goal

Destroy missiles before they reach the ship. You have **3 hull hits**. Waves get faster and denser. Score climbs with each intercept.
